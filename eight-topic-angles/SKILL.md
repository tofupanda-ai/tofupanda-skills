# 爆款选题八角度

## 触发条件

用户提出以下任一意图时使用本技能：
- 「给我出选题」「这个标题行不行」「帮我想几个角度」
- 提供一个主题、一条素材链接、一篇对标文章，希望扩展成可写的内容方向

## 核心方法

对同一个主题，用八个固定词根各推演一次，每个角度必须产出：钩子句（可直接当标题）、论点（正文骨架）、下一步（可执行动作）。

提示词模板：我是做 ___（行业）的，请围绕这八个词给我出八个选题：成本、人群、最差、头牌、猎奇、反差、荷尔蒙、怀旧——每个词必须带词根和例子，否则不会推理。

### 八字诀

1. **成本**：花小钱办大事、最省事。例：99 块六盘菜探店。产出钩子必须带具体数字。
2. **人群弱势**：让没见过世面的人代入。例：天生皮肤黑吃什么水果能变白。
3. **最差**：好奇差到什么地步。例：2.7 分外卖差评菜开箱。子词：最丑、最难吃、评分最低。这一角度经常产出最有价值的内容点——烂在哪里就是内容点。
4. **头牌**：名人、名校、名企、最贵。例：北大毕业跑去小山村。
5. **猎奇罗列**：固定排比。例：明朝宋朝汉朝各自怎么美白。
6. **反差对比**：一捧一踩，必须带具体数字捅刀子。例：北大理科生为什么比清华工资高三千。无具体数字的反差角度不合格。
7. **荷尔蒙**：情爱、魅力、择偶。例：男生真的喜欢超白的女生吗。
8. **怀旧**：古代、二十年前、小时候。例：古代美女怎么美白。可叠加任意主题。

### 第九步：逆向自查（必须执行）

八个角度生成后，追问：「哪条撞了最近两周的全网热帖共识？」对每个角度反着用一次：
- 头牌逆向：大厂出来的为什么混得不好
- 成本逆向：省钱反而花更多的坑
- 爆款方法论逆向：爆款归因学是个重大误解

逆向纪律：反驳完成后，读者必须拿到顺共识看不到的事实或机制；拿不到就毙稿。逆向不是逢共识必反。

## 输出格式

每个角度一张选题卡：

```
角度：反差对比
钩子：AI 扩 8 个选题方向花 3 分钟，实习生手写两天
论点：1) 生成过程实录 2) 质量对比截图 3) 时间成本核算
下一步：实测一次 8 方向扩写，截图计时
```

## 质量自查

- 每条钩子是否有具体数字或具体动作？没有就重推
- 反差角度有没有具体数字？没有就不合格
- 逆向检查是否执行？跳过则整批角度可能全是饱和选题
- 命中角度数为零的选题大概率平淡，重新换主题或换角度组合
