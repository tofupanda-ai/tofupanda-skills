# 短视频脚本结构

## 触发条件

- 用户给一个内容角度、选题卡或文章，要求转成短视频脚本
- 用户要求写带货、工具实测、教程类 60 秒视频脚本

## 脚本结构（60 秒模板）

| 时间段 | 内容 | 硬要求 |
|---|---|---|
| 0-3s | 最终效果、对比或核心冲突 | 前 3 秒必须出对比或冲突，钩子用结果不用过程 |
| 3-8s | 翻车、问题放大 | 放大细节，制造共鸣 |
| 8-14s | 原始素材展示 | 交代参照物 |
| 14-30s | 操作过程屏录 | 首次提及产品用全名 |
| 30-48s | 核心成果展示 | 前后对比是全片高潮 |
| 48-56s | A/B 同屏对比 | 关键节点逐个对齐 |
| 56-60s | 结论加体验入口 | 带官网或评论区置顶 |

## 输出格式

分镜表每格写清五列：时间段、画面、口播、备注、对应硬要求。

发布配置三件套：

1. 标题：抖音版（直接）+ 小红书版（情绪化）
2. 话题标签：按平台热度选 3-5 个
3. 封面：对比分屏加大字

小红书改法：标题换情绪化表达，正文前 3 行必须包含翻车、解决方案、工具名三要素，图 1 放对比图。

## 商单附加规则（如为商单）

- 商单硬性要求逐条对照商单原文，分镜表备注列标注对应关系
- 发布前逐条勾选自查：功能路径完整、对比组齐全、首次提及用全名、结尾带入口

## 发布前自检清单

- 前 3 秒有对比或冲突
- 首次提及产品用全名
- 前后对比是全片高潮
- 结尾带体验入口
- 双平台标题与标签已配置
