# Tofu Panda Skill Packs

为内容创作者准备的 AI Agent 技能包。每个技能是一份标准 SKILL.md（AgentSkill 格式），兼容 Codex CLI、ZCode、WorkBuddy 等支持 Agent Skills 的运行环境。

## 技能清单（免费版）

| 技能 | 说明 | 适合谁 |
|---|---|---|
| eight-topic-angles | 爆款选题八角度：一个主题变成 8 个可执行内容角度加逆向自查 | 做公众号、短视频、小红书的内容创作者 |
| content-fact-check | 内容事实核查：草稿变成可疑论断清单加逐条核查建议 | 写测评、核价、数据类文章的作者 |
| short-video-script | 短视频脚本结构：内容角度变成 60 秒分镜级脚本加双平台发布配置 | 抖音、小红书带货或工具实测类视频作者 |

## 安装

### Codex CLI / ZCode

```bash
git clone https://github.com/tofupanda-ai/tofupanda-skills.git
# 把对应技能目录拷贝到你的 skills 目录，例如：
# cp -r tofupanda-skills/eight-topic-angles ~/.codex/skills/
```

### WorkBuddy

1. 打开 WorkBuddy，进入技能板块，点添加技能，选上传技能包
2. 选择本仓库对应技能目录（含 SKILL.md 的文件夹）
3. 或通过 SkillHub（skillhub.cn）搜索 Tofu Panda 获取
